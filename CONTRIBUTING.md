# Contributor setup

Use Node.js 24 and npm. Run `npm ci`, `npm run dev`, `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build`. This is static Vite React TypeScript with base `/Feedback-Nexus/`.

Sample data and calculations: `src/model.ts`. Persistence: `src/storage.ts`. Interface: `src/main.tsx`. Keep new behavior observable and limits documented. Do not introduce live services, keys, analytics, or invented outcomes. Use substantive commits. Browser storage key: `mo-feedback-nexus-v1`.
